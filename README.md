# Fernq

**A next-generation compiler for Rust.**

Fernq is an independent compiler for the Rust programming language.

The project is currently in its earliest stage. Architecture, compatibility targets, implementation details, and benchmarks will be documented as the project develops.

## Status

Early development.

## Goals

Fernq aims to explore a new compiler implementation for Rust with a strong focus on:

- Rust language and ecosystem compatibility
- compilation performance
- incremental compilation
- generated code quality
- predictable resource usage
- correctness
- maintainability

Specific architectural decisions and performance claims will only be documented once they have been researched, implemented, and measured.

## Development

Fernq is written in Rust.
